# Twitch StreamSync – Twitch Plugin for Unreal Engine

**Twitch StreamSync** is a production-ready **Twitch plugin for Unreal Engine** that lets you integrate **Twitch chat, EventSub, Channel Points, subscriptions, polls and predictions** directly into your game using **Blueprint-first workflows**.

No backend server required. No custom WebSocket handling.  
Just clean Unreal Engine integration.

---

## 🚀 What is Twitch StreamSync?

Twitch StreamSync is an Unreal Engine plugin designed to help developers build **real Twitch-driven gameplay**.

It allows your game to:
- React to Twitch chat messages
- Receive real-time Twitch events (EventSub)
- Use Channel Points to trigger gameplay
- Handle OAuth securely
- Prototype Twitch interactions offline

All **inside Unreal Engine**, without writing external services.

## 🔑 Key Features

### 🗨️ Twitch Chat (IRC via WebSocket)

### ⚡ Twitch EventSub (WebSocket & Webhook)

- Channel Points redemptions

- Automatic token refresh

### 🧪 Dev Simulator
