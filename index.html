Core Features of the Twitch Plugin for Unreal Engine

Twitch IRC Chat Integration

Connect to Twitch chat via secure WebSocket. Receive messages, send commands, and manage moderation directly inside Unreal Engine.

Twitch EventSub (WebSocket)

React to real-time Twitch events such as Channel Points, subscriptions, raids, polls and predictions — no backend required.

Helix API Control

Update stream title and category, manage polls and predictions, and control Twitch features directly from your game.

OAuth 2.0 Authentication

Secure OAuth flow with automatic token refresh and scope validation, fully handled by the plugin.

Dev Simulator

Test Twitch-driven gameplay offline by simulating real events without streaming or spamming chat.

Production Logging

Detailed logging and diagnostics with automatic masking of secrets and sensitive data.

  • Windows 64-bit

Dependencies

  • Unreal's built-in HTTP, WebSockets, and SSL modules

External Requirements

  • Twitch Developer Application with Client ID and Secret
  • Redirect URI: http://localhost:8080/Auth
  • No external server required (except Webhook mode)
