Complete guide to integrate Twitch into your Unreal Engine projects with StreamSync

Overview

Twitch StreamSync is a comprehensive Unreal Engine plugin designed to seamlessly integrate Twitch functionality into your games. Built with a Blueprint-first approach, it handles OAuth authentication, chat interactions, real-time events, and stream management without requiring complex backend infrastructure.

Core Philosophy

StreamSync is built around three principles:

  • Blueprint-First: Complete functionality accessible through visual scripting
  • Production-Ready: Built-in safety measures for handling live traffic spikes
  • Backend-Optional: WebSocket-based by default, no server required

Core Components

Authentication

Handles OAuth 2.0 flow, token management, and silent refresh automatically

Chat (IRC)

Connect to Twitch chat via secure WebSocket with message queuing and moderation tools

EventSub

Receive real-time notifications for subs, raids, channel points, polls, and more

Helix API

Update stream metadata, create rewards, manage polls and predictions

Dev Simulator

Test all functionality offline without going live or spamming chat

Safety Features

Message queuing, rate limiting, and automatic throttling for production stability

Scopes

Scopes are OAuth permissions that define what your game can do on behalf of the streamer. Think of them as capability gates: without the correct scope, specific features simply won't be available.

Scope Strategy

Request only what you need. Over-requesting permissions reduces trust and can make your integration feel invasive. StreamSync is designed so missing scopes gracefully disable features rather than breaking your game.

TwitchAuthentication

The TwitchAuthentication component is the trust anchor of StreamSync. It manages the complete OAuth 2.0 lifecycle: launching authorization, receiving and storing tokens, validating scopes, and exposing user identity to your Blueprints.

Key Features

  • OAuth 2.0 Flow: Handles browser-based authorization with local callback server
  • Token Storage: Securely stores access and refresh tokens
  • Silent Refresh: Automatically renews tokens before expiration
  • Scope Validation: Checks and reports missing permissions
  • User Data: Fetches channel info, stream status, followers, and more

Security & Lifecycle

Once authenticated, the token becomes the shared credential used by Chat, EventSub, and Helix. StreamSync tracks token expiry and refreshes automatically in the background, so your game stays connected without repeatedly opening browsers or forcing re-login.

Setup Requirements

Client ID

From your Twitch Developer Application

Client Secret

Generated in Twitch Dev Console

Redirect URI

http://localhost:8080/Auth (for local WebSocket mode)

Main Nodes

<Initialize Twitch Integration> <Fetch User Info> <Refresh Stream Data> <Validate OAuth Token> <Refresh Access Token Silent>

Token Refresh Strategy

Access tokens expire after a few hours. StreamSync monitors the expiration time and calls RefreshAccessTokenSilent() automatically. No browser popup, no manual intervention—just continuous, stable authentication.

TwitchChat

The TwitchChat component connects to Twitch IRC using secure WebSockets. It provides high-level interfaces for sending messages, receiving chat, registering commands, and applying moderation actions—all within Unreal's event-driven Blueprint system.

Performance & Safety

Chat traffic can spike massively during raids or high-activity streams. To protect your frame rate, StreamSync implements a message queue system that buffers incoming IRC lines and releases them at a controlled rate per tick.

Message Queue

Buffers up to 2000 messages (configurable)

Dispatch Control

Max 200 messages per tick (configurable)

Overflow Protection

Drop oldest/newest when queue is full

Chat Features

  • Send Messages: Post to chat or execute commands
  • Register Commands: Create custom !commands with callbacks
  • Moderation: Ban, timeout, clear chat, set slow/follower/emote-only mode
  • Channel Override: Connect to other channels (for mods)
<Auto Connect Chat> <Send Message> <Register Command> <Set Slow Mode> <Clear Chat> <Perm Ban User>

Command Registration

Use Register Command to create custom commands. Set your preferred prefix (!, ?, etc.) with Setup Command Characters. Each command triggers a Blueprint callback with parsed arguments.

Configuration Parameters

Parameter Default Description
Use WebSocket IRC True Firewall-friendly WebSocket connection (recommended)
Max Queue Messages 2000 Maximum buffered messages before overflow
Max Dispatch Per Tick 200 Maximum messages delivered per frame
Drop Oldest On Overflow True If true, drops old messages; if false, drops new ones

EventSub

EventSub is Twitch's official real-time event delivery system. It provides structured, reliable notifications for everything that happens on stream: subscriptions, channel points, raids, follows, polls, predictions, and much more.

Transport Modes

WebSocket (Default)

Client maintains outgoing connection to Twitch. No backend required, works in Editor and packaged builds.

Webhook (Advanced)

Twitch sends HTTPS POST to your public URL. Best for dedicated servers and centralized processing.

Which Mode to Choose?

WebSocket: Perfect for games, single-user tools, and development. Simple, fast, NAT-friendly.
Webhook: For backend environments, multi-streamer support, or always-on event capture.

Event Types

  • Channel Points: Redemptions, reward created/updated
  • Subscriptions: New subs, resubs, gift subs
  • Raids: Incoming raids from other channels
  • Follows: New follower events
  • Bits: Cheer/Bits events
  • Polls: Poll begin, progress, end
  • Predictions: Prediction begin, progress, lock, end
  • Hype Trains: Hype Train begin, progress, end
  • Moderation: Ban, timeout, moderator add/remove
<Apply EventSub Selection (Bools)> <Subscribe Channel Points> <Subscribe to All Standard Events> <List Subscriptions>

Event Parsing

Each event type has a dedicated Parse<EventType> node that breaks down the data structure. For example, a channel point redemption gives you: user, reward title, cost, user input, and redemption ID.

Subscription Best Practice

Use Apply EventSub Selection (Bools) to subscribe to multiple topics at once. Check only what you need, then call the node. To unsubscribe, simply uncheck topics and call again.

Dev Simulator

The Dev Simulator is a powerful development tool that lets you trigger Twitch-like events locally without going live. Perfect for iteration, testing, and debugging your game logic offline.

Benefits

Offline Testing

Test all functionality without streaming or connecting to Twitch

Reproducibility

Trigger exact events with controlled parameters

Fast Iteration

Validate UI and gameplay reactions instantly

Simulated Events

  • Channel Point Redemptions
  • Subscriptions & Gift Subs
  • Raids
  • Follows
  • Bits/Cheers
  • Chat Messages
  • Polls & Predictions
  • Hype Train Events
<Simulate Twitch Event> <Make Channel Point Sim Params> <Make Subscription Sim Params> <Make Raid Sim Params>

How to Use

1. Call Simulate Twitch Event
2. Select the event type you want to simulate
3. Create corresponding Make <Event> Sim Params
4. Fill in test data (username, amounts, messages, etc.)
5. Your Blueprint events fire exactly as if it came from Twitch

Production Stability

The simulator shares the same event pipeline as real Twitch events. This means your game logic remains testable even when Twitch is unavailable, when you're not streaming, or when you need to reproduce complex event chains deterministically.

Important

The Dev Simulator requires both TwitchAuthentication and TwitchEventSub components to be properly set up. Without them, simulated events won't trigger correctly.
